# Overstepping boundaries on ambiguous and high-risk tasks (Active / Counter Collaboration)

- Slug: ambiguous-high-risk-task-collaboration-eval
- What it measures: Whether an agent pauses to clarify on underspecified/ambiguous/high-risk SWE and non-coding tasks (Active Collaboration) while executing unambiguous tasks without friction (Counter Collaboration).
- Metric: Active Collaboration Score; Counter Collaboration Score (Pareto frontier).
- Open-source: n
- Runnable on a 0.5B-7B open model: y in design.
- Source URL(s): https://storage.googleapis.com/deepmind-media/gemini/gemini_4_safety_report.pdf
- Fetched: 2026-10-19

## Description
"raising the Active Collaboration rate from 34.0% to 55.9% compared to Gemini 3.8 Flash ... keeps Counter-Collaboration on clear tasks comparable (84.5% vs. 86.5%, within the confidence interval)" (p.186).
