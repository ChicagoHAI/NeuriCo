# OpenAI static and multiturn jailbreak evaluations

- Slug: openai-static-multiturn-jailbreaks
- What it measures: Robustness of the bare model (no production classifiers) to (a) a fixed set of adversarial prompts generated by attacker models, half from a held-out attacker, across bio/violence/cyber risk tiers, and (b) adaptive multi-turn attackers derived from internal red-teaming.
- Metric: static: proportion of attacks refused, with 95% CIs. multiturn: worst-case defender success rate as a function of attacker budget n (model must resist all n attempts).
- Open-source: n (attack sets and attacker models internal; GPT-Red described in arXiv 2607.26115)
- Runnable on a 0.5B-7B open model: n as-is; the multiturn worst-case-vs-budget metric is worth copying with public attacker sets.
- Source URL(s): GPT-6 Astra System Card, https://deploymentsafety.openai.com/gpt-6-astra (Table 5, Fig 3); GPT-5.6 card
- Fetched: 2026-10-19

## Description
Astra reports .915-.983 static refusal vs .058-.590 for GPT-5.6 Sol, which OpenAI attributes to the prompts having been designed to break earlier models plus new robustness training; half of each eval's prompts come from a held-out attacker to test generalisation. The multiturn eval is reported only as a figure. Both measure "one layer of robustness in our safety stack" - production classifiers are excluded.
