# DeepSeek 50-language safety set (R1 Nature supplement)

Fetched: 2026-10-19

- What it measures: 9,330 safety questions translated into 50 languages, scored 5/4/0 per answer; aggregate % of maximum safety score and count of 'high-risk' languages (<60).
- Metric: % of max safety score; number of languages below 60.
- Open-source: no
- Link: https://arxiv.org/abs/2501.12948 (v2 Supplementary D.3.4 Figure 14)
- Runnable on a 0.5B-7B open model: no (private)

Used by: DeepSeek (R1 Supp. D.3.4: with RC V3 86.5, R1 85.9, Claude-3.7 88.3; without RC V3 75.3, R1 74.2, GPT-4o 75.2; high-risk languages R1 0, V3 1)
