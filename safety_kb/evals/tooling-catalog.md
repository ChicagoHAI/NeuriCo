# Safety-eval tooling catalog

Fetched: 2026-10-19. Every row below was checked against the repo README / docs / PyPI /
HF API on this date (licence and "last push" come from the GitHub API; HF ids from the HF
API). Anything not confirmed from a fetched page is marked UNVERIFIED. Compute figures are
our own estimates unless a source is cited. Per-family detail lives in `evals/<slug>.md`.

Conventions for the "Interfaces" column: HF = local `transformers`; vLLM = local vLLM
(offline or OpenAI-compatible server); OAI = OpenAI-compatible HTTP API (so also vLLM
server / OpenRouter / LiteLLM proxies); ANT = native Anthropic API; OR = OpenRouter named
explicitly in docs. "Small-model OK" = can run end-to-end on a 0.5B-3B Qwen on one A6000
(judge may still be an API model).
