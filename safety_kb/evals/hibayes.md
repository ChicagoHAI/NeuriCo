# HiBayES (hierarchical Bayesian evaluation statistics)

- Slug: hibayes
- What it measures: Not an eval: statistical framework for hierarchically structured, small-sample LLM evaluation data
- Metric: Posterior estimates with uncertainty across items/subdomains/models
- Open-source: y (paper https://arxiv.org/abs/2505.05602; code release UNVERIFIED)
- Runnable on a 0.5B-7B open model: n/a
- Source URL(s): https://www.aisi.gov.uk/blog/hibayes-improving-llm-evaluation-with-hierarchical-bayesian-modelling
- Fetched: 2026-10-19

## Description
"a hierarchical Bayesian modelling framework" addressing that "Conventional analysis methods are known to overfit evaluation data and do not systematically quantify uncertainty across levels of the data hierarchy".
