# GAIA (General AI Assistants)

- Slug: gaia
- What it measures: General assistant tasks requiring web browsing, tool use and multi-step reasoning
- Metric: Exact-match accuracy by level
- Open-source: y: inspect_evals gaia ; https://huggingface.co/gaia-benchmark
- Runnable on a 0.5B-7B open model: y (tool-using agent; small models score low)
- Source URL(s): https://www.aisi.gov.uk/blog/inspect-evals ; https://github.com/METR/task-standard
- Fetched: 2026-10-19

## Description
Included in Inspect Evals as an agent benchmark ("The collection includes several agent benchmarks including GAIA, SWE-Bench, GDM CTF"); METR Task Standard ships a GAIA adaptor.
