# Sabotage Evaluations for Frontier Models (Anthropic x Redwood)

- Slug: sabotage-evals
- What it measures: Capability to covertly sabotage evaluations, monitoring, or deployment decisions of a frontier developer under given mitigations (human decision sabotage, code sabotage, sandbagging, undermining oversight)
- Metric: Mitigation-aware capability thresholds; small-scale statistics extrapolated to large deployments
- Open-source: partial (paper; code UNVERIFIED)
- Runnable on a 0.5B-7B open model: n as published
- Source URL(s): https://arxiv.org/abs/2410.21514
- Fetched: 2026-10-19

## Description
"These evaluations are designed to provide evidence that a given model, operating under a given set of mitigations, could not successfully sabotage a frontier model developer or other large organization's activities"; demonstrated on Claude 3 Opus and 3.5 Sonnet; basis of Anthropic's later Sabotage Risk Reports reviewed by METR.
