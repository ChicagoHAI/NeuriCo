# Anthropic open-source tools, datasets and methods for safety evaluation

Fetched: 2026-10-19. Repo metadata from the GitHub API and READMEs (saved under
`sources/anthropic/repos/`); descriptions from the linked Anthropic posts. "Runnable on open models"
means: the tool targets any model behind an API or HF/vLLM endpoint, so a 0.5B-7B open model can be the
*target*; the auditor/judge roles usually need a strong model (Claude/GPT) via API, although Inspect-based
tools accept any provider.

## Methods described in detail but not released (to replicate)
- Automated behavioral audit (the internal, larger Petri: ~1,900-2,100 handwritten seeds, real sandboxes,
  Claude Code harness, internal codebases, fallback classifiers; several dozen judge dimensions, see
  system-cards.md A).
- Opportunistic sandbox-escape eval (1,753 scenarios, 26 sandboxes, "tempters", Firecracker outer VM).
- Secret-keeping eval (39 job environments, counterpart reads reasoning).
- Rare-action eval (Serrano et al. 2026 replication, 4,000 samples per setting).
- CoT-controllability (Chen et al. 2026, GPQA/HLE/MMLU-Pro; UK AISI prompt).
- White-box NLA + template-lens investigator pipeline; judge rubric 1-10 with >=6 threshold.
- RL reward-hacking classifiers; impossible-task analysis; grader-awareness autorater with disclosure bands.
- Destructive-action resampling from real transcripts; user-pasted-text injection eval; package-registry eval.
- CoBench (historical codebase snapshots, root-cause diagnosis); AECI (IRT over 374 benchmarks).
- Offline monitoring pipeline (Opus 4.6 CoT monitor + Opus 4.8 prompt+completion monitor, impactful-action
  probe, second-stage summarisation).
- Realism win-rate metric (Kissane et al., Mar 2026): fraction of audit transcripts an LLM judge mistakes for
  real deployment transcripts (4.6% -> 32.8% with deployment resources).
